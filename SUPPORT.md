# 💬 Getting Support for Aegis Invariant Kernel

Thank you for building with **Aegis Invariant Kernel**! We are committed to providing first-class support to open-source contributors, enterprise teams, and agent engineers.

---

## 🧭 Support Channels

### 1. 💡 GitHub Discussions (Community Q&A & RFCs)
For general architecture questions, agent framework integration inquiries (LangChain, OpenAI Swarm, Anthropic, LlamaIndex), and design RFCs:
- **[GitHub Discussions](https://github.com/Snehgabani/aegis-kernel/discussions)**
- Categories: `Q&A`, `Ideas & RFCs`, `Show and Tell`, `Rule Pack Proposals`.

### 2. 🐛 Bug Reports & Feature Requests
If you encounter a reproducible bug, invariant edge case, or parser divergence:
- **[Create an Issue](https://github.com/Snehgabani/aegis-kernel/issues/new/choose)**
- Please use the structured issue templates to include minimal reproduction code.

### 3. 🔒 Security Vulnerability Disclosures
**DO NOT report security vulnerabilities via public GitHub issues.**
- Please refer to our **[Security Policy](SECURITY.md)**.
- Report vulnerabilities securely via GitHub Private Vulnerability Reporting at [https://github.com/Snehgabani/aegis-kernel/security/advisories/new](https://github.com/Snehgabani/aegis-kernel/security/advisories/new).
- Response SLA: Within **24 hours**.
