# @aegis-kernel/cli

Developer CLI tool for Aegis Invariant Kernel.

## Installation

```bash
npm install -g @aegis-kernel/cli
```

## Commands

- `aegis init` — Initialize `aegis.config.yaml` and `.aegis/` directory.
- `aegis test` — Execute synthetic attack vectors and generate Agent Safety Scorecard.
- `aegis report` — Display disaster prevention metrics and rule health from Learning Ledger.
